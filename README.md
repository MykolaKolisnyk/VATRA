# VATRA

Українська соціальна мережа. Репозиторій основного сайту VATRA (не VATRA-BETA).

## Навігація по коду

| Папка / файл | Для чого |
| --- | --- |
| `*.html` у корені | Сторінки, адреси GitHub Pages |
| `assets/js/` | JavaScript сайту |
| `assets/css/` | Стилі сайту |
| `assets/i18n/` | Переклади |
| `assets/logo/`, `assets/vatryk/`, `assets/fonts/` | Графіка та Onest |
| `tests/smoke/` | Функціональні тести |
| `tests/audit/` | Автоматичні аудити |
| `tools/` | Збірка та контроль версій ресурсів |
| `supabase/` | Міграції, Edge Functions і SQL |
| `email-templates/` | Шаблони листів |
| `docs/` | Пояснення архітектури |

Детальні правила та схема: [Структура VATRA](docs/asset-architecture.md). Безпека повідомлень: [Messenger](docs/messenger-security.md).

HTML залишається в корені, оскільки перенесення змінить URL сторінок та шляхи до ресурсів. Код тестування відокремлено від робочого коду. Непотрібні дублікати й старі селектори прибираємо лише разом із перевіркою їх використання.
