# ВАТРА — українська соціальна мережа

Поточний варіант готується до переходу з Firebase на Supabase. Основна версія клієнта міститься у папці `vatra-v9/`; кореневі сторінки перенаправляють до неї.

## Статус міграції

- Supabase Auth для реєстрації та входу.
- Supabase Postgres для профілів, дописів, коментарів, вподобань, дружби, спільнот, повідомлень і збереженого.
- RLS-політики для обмеження доступу до приватних даних.
- Base64-медіа для аватарів, обкладинок і вкладень у межах клієнтських лімітів.
- Адаптивний інтерфейс для настільних і мобільних пристроїв.

## Перед запуском

1. Відкрий `vatra-v9/supabase-schema.sql` і виконай його в SQL Editor потрібного Supabase-проєкту.
2. Перевір `vatra-v9/supabase-client.js`: у ньому мають бути URL проєкту та publishable key. Ніколи не додавай `service_role` або secret key у браузерний код.
3. Перевір реєстрацію, підтвердження пошти, створення профілю, дописи, лайки, коментарі, опитування, дружбу, повідомлення й збережене двома тестовими акаунтами.
4. Не вважай міграцію завершеною, доки SQL не виконано й основні сценарії не перевірено.
