# VATRA

VATRA — соціальна платформа. Поточний репозиторій містить авторизацію, реєстрацію, відновлення пароля та інформаційні сторінки.

## Структура

- `index.html` — головна сторінка з реальною формою входу та метаданими для пошукових систем
- `auth.html` — вхід у тому ж затвердженому дизайні, що й головна сторінка
- `register.html` — реєстрація
- `forgot.html` — відновлення пароля
- `reset.html` — створення нового пароля
- `account.html` — захищена сторінка після входу
- `legal.html` — сторінка документів
- `assets/css/auth.css` — локальний шрифт Onest та спільні стилі авторизації
- `assets/js/auth.js` — логіка Supabase Auth
- `assets/logo/` — завантажені офіційні логотипи VATRA у SVG та PNG. Використовувати тільки їх, не перемальовувати.

## Налаштування Supabase

У проєкті Supabase VATRA встановіть **Site URL** `https://mykolakolisnyk.github.io/VATRA/` і додайте дозволені Redirect URLs:
- `https://mykolakolisnyk.github.io/VATRA/account.html`
- `https://mykolakolisnyk.github.io/VATRA/reset.html`

Підтвердження email та відновлення пароля вимагають налаштованого надсилання email. Для реального публічного запуску підключіть SMTP-провайдера; стандартний поштовий сервіс Supabase має обмеження. Не додавайте до репозиторію секретні ключі. У клієнті використовується лише публічний publishable key.

Номер телефону поки не підтримується — потрібен окремий SMS-провайдер. Інші можливості VATRA впроваджуватимуться окремо.

## Шрифт Onest

- `assets/fonts/Onest-Variable.ttf` — оригінальний змінний шрифт Onest (100–900), завантажується **тільки з цього репозиторію**.
- `assets/fonts/OFL.txt` — текст відкритої ліцензії SIL Open Font License 1.1.
- У файлі `assets/css/auth.css` шрифт підключений локальним `@font-face`. Зовнішній Google Fonts не використовується.

## Пошук та індексація

- `index.html` має унікальний title, description, canonical URL, Open Graph, Twitter Card та структуровані дані WebSite.
- `sitemap.xml` містить публічну головну сторінку та чотири публічні сторінки з документами. Її можна додати до Google Search Console.
- Сторінки входу, реєстрації, відновлення та акаунта мають `noindex`. Документи й головна сторінка — публічні.
- Відкритий запуск, постійна адреса сайту та політики потребуватимуть оновлення метаданих.

## Правила та приватність

- `legal.html` — огляд документів.
- `terms.html` — власні умови використання VATRA.
- `privacy.html` — власна політика конфіденційності VATRA.
- `cookies.html` — пояснення cookies та localStorage.
- `assets/css/legal.css` — стилі документів, без повторів у головних стилях.

**Перед повноцінним запуском:** необхідно додати справжні дані володільця інформації та приватний канал для звернень, описати процедуру видалення акаунтів, реальні строки зберігання даних і перевірити документи з юристом. Документи мають бути юридично перевірені перед публічним запуском. Функції маркетплейсу та платні сервіси ще не діють і потребуватимуть окремих умов.

## Адаптивність та хостинг

- Сторінки розраховані на ПК, планшети та смартфони. SVG-логотипи отримують адаптивну висоту, щоб шапка не розтягувалася.
- `assets/js/host.js` перевіряє офіційне HTTPS-розміщення `mykolakolisnyk.github.io/VATRA/`; звичайний запуск з `file://` і localhost блокується.
- **Це лише клієнтське обмеження, а не захист авторського коду:** скопійований HTML/JS можна змінити. Справжні обмеження даних, платіжних операцій і платних можливостей мають бути на сервері, з автентифікацією та перевіркою прав.
