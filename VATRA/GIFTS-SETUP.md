# Подарунки ВАТРИ — серверне впровадження

1. У Supabase SQL Editor виконайте `VATRA/vatra-gifts.sql`. Потрібна функція `public.vatra_data_is_friend` із `app-data-schema.sql`. Без SQL інтерфейс подарунків відкривається в режимі ознайомлення, але не показує вигадані запаси.
2. Подарунки — окремі облікові одиниці, а не просто картинки. Передавання виконується атомарною RPC і лише друзям. Користувач НЕ може сам видати собі платний подарунок через браузер.
3. Святкові подарунки автоматично видаються під час відвідування розділу у святкову дату за часовим поясом Києва: 31 жовтня (Гелловін), 1 січня (Новий рік), 24 серпня (День Незалежності). Один подарунок кожного виду на рік, повторні виклики безпечні.
4. Платні подарунки: передбачено каталог і захищений запис про право власності, але **онлайн-оплата не підключена**. Покупку необхідно узгодити з розробником, після підтвердженої оплати розробник видає подарунок через захищену серверну дію або SQL Editor. Ніколи не видавайте подарунок тільки за повідомленням клієнта «я оплатив».
5. Приватність — «Для всіх», «Для друзів», «Лише для мене». При читанні подарунків інших користувачів доступ перевіряється у SQL, а не лише CSS.
6. Векторні зображення в `vatra-gifts.js` є оригінальними для ВАТРИ. Не використовуйте стікери або зображення з VK, а також назви чи графіку чужих сервісів.

Перед продажем за реальні гроші необхідно додати документовану ціну, оплату через провайдера, серверну перевірку платежу, правила повернення й бухгалтерські/правові реквізити продавця. Жодні платіжні токени не зберігаються на фронтенді.
