# ВАТРА — налаштування авторизації Supabase без кодів підтвердження

Поточна збірка ВАТРИ використовує вхід і реєстрацію за email або номером телефону та паролем. **OTP-код не використовується під час звичайного входу чи створення акаунта.** Supabase зберігає захищену сесію у браузері; у ВАТРІ немає окремого списку збережених контактів.

## 1. Обов’язкові перемикачі в Supabase

Відкрий Supabase Dashboard саме для проєкту, адресу якого вказано в `vatra-backend.js`.

1. Увімкни **Allow new users to sign up**.
2. В Authentication → Sign In / Providers → Email вимкни **Confirm email**.
3. Для реєстрації за номером увімкни **Phone provider**, але вимкни **Confirm phone**.
4. Збережи налаштування і протестуй новий контакт. Після створення акаунта має повертатися активна сесія. Якщо сесії немає, поточний код зупиняє процес і показує повідомлення про потрібні налаштування.

Назви пунктів можуть трохи відрізнятися між версіями панелі Supabase.

## 2. Контакти й дублікати

Supabase Auth відповідає за унікальність email і номера. ВАТРА обробляє відповідь Supabase про зайнятий контакт, але не шукає акаунти публічним запитом до реєстрації: такі запити можуть розкривати, чи має хтось акаунт. Не вимикай RLS і не додавай service-role key у фронтенд.

**Компроміс режиму без OTP:** контакт не доведено належить конкретній людині. Користувач може помилитися в адресі/номері, а номер згодом може перейти іншій людині. Для публічного запуску потрібні серверна CAPTCHA, ліміти запитів і моніторинг. Інтерфейсна «Швидка перевірка» не замінює серверну CAPTCHA.

## 3. Паролі

Форма ВАТРИ вимагає щонайменше 12 символів, малу та велику латинські літери, цифру й спецсимвол. Краще використовувати унікальний пароль від 16 до 20 символів або довгу парольну фразу, згенеровану менеджером паролів. Приклад з форми не копіюй дослівно. У налаштуваннях Password security узгодь серверну політику складності й увімкни перевірку на витоки, якщо вона доступна. Індикатор у браузері лише підказує й не замінює серверну перевірку.

## 4. Відновлення пароля — окремо

Відновлення може надсилати email-інструкцію або SMS-код. Для email перевір SMTP, шаблон Reset Password та Authentication → URL Configuration (redirect на `auth.html?mode=new-password`). Для SMS перевір Phone provider, налаштування SMS-провайдера, баланс і журнали провайдера. Ці налаштування не потрібні для звичайного входу за паролем.

## 5. Помилки дописів/даних

Виконай актуальний `VATRA OLD/app-data-schema.sql` у Supabase SQL Editor у правильному проєкті. Не вимикай Row Level Security для обходу помилки: перевір конкретне правило доступу й журнал помилок.
