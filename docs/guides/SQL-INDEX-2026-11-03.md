# Історичний каталог SQL ВАТРА — 3 листопада 2026

Історичний каталог, складений 3 листопада. Нинішня структура впорядкована в [database/README.md](../../database/README.md). Це не інструкція повторно запускати міграції. Усі посилання ведуть до тексту в GitHub.

> **Важливо:** це каталог, а НЕ список команд «запустити все». Деякі SQL-файли — старі міграції, альтернативні версії, основна схема та зміни, які залежать від уже наявних таблиць. Застосування всіх файлів підряд може зламати правила доступу або змінити робочу схему. Спершу зробіть резервну копію, перевірте, які міграції вже виконані, і протестуйте на окремому Supabase-проєкті.

## Перед запуском

1. Перевірити назву та адресу Supabase-проєкту.
2. Зберегти резервну копію БД і мати план відкату.
3. У першу чергу запустити [read-only аудит](../../database/audits/supabase-read-only-audit.sql), оцінити наявні таблиці, тригери, функції й політики RLS.
4. Увімкнути потрібні серверні функції окремо після SQL. **Ключі сервісного доступу ніколи не вставляти в браузерний код.**
5. Перевірити права трьох акаунтів: звичайного користувача, адміністратора спільноти та власника.

Відомі обмеження: скрипти й функції в GitHub не доводять, що вони вже запущені у вашій робочій базі.
