# ВАТРА — статус міграції та безпеки

Активний код у цій гілці переводиться на Supabase. Старі Firebase правила й попередні нотатки v13 не є конфігурацією для нової версії.

## Підготовлено
- Supabase Auth для входу й реєстрації.
- Postgres-таблиці для профілів, дописів, коментарів, лайків, друзів, спільнот, повідомлень, збереженого, опитувань, сповіщень і скарг.
- RLS-політики та тригери сповіщень.
- Base64 для зображень та відео в межах клієнтських обмежень.

## Не вважати перевіреним до тестування
1. SQL-файл ще потрібно виконати в цільовому Supabase-проєкті.
2. Політики доступу мають бути перевірені двома різними акаунтами, зокрема на приватних профілях, дописах і повідомленнях.
3. Base64 не є шифруванням і збільшує розмір даних.
4. Наскрізне шифрування повідомлень (E2EE) не реалізовано.
5. Скарги зберігаються в базі, але повноцінна адмін-панель модерації ще не реалізована.
6. Не заявляти про абсолютну безпеку або готовність до широкого запуску до завершення перевірок.
