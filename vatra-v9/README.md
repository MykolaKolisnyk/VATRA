# ВАТРА — Supabase edition

Це клієнтський вебзастосунок ВАТРИ, який переводиться на Supabase замість Firebase.

## Основні файли
- `index.html` — основний інтерфейс.
- `auth.html` — окрема сторінка входу та реєстрації.
- `supabase-client.js` — публічний клієнтський URL та publishable key.
- `script.js` — логіка стрічки, профілів, дописів, друзів, спільнот, повідомлень та опитувань.
- `auth.js` — Supabase Auth.
- `supabase-schema.sql` — таблиці, RLS-політики та тригери.
- `vatra-supabase.css`, `auth-supabase.css` — додаткові адаптивні стилі.

## Запуск
Спочатку виконай `supabase-schema.sql` у SQL Editor відповідного проєкту. Потім відкривай сайт через локальний сервер або GitHub Pages, не через `file://`.

У браузерному коді дозволено використовувати лише publishable/anon key. Не додавай secret або service_role key.

## Поточні обмеження
Це міграційний варіант. Перед публічним запуском перевір усі основні сценарії з двома тестовими користувачами та переконайся, що політики RLS відповідають очікуваній приватності.
