# Архів старих модулів

У [legacy-ui/](legacy-ui/) збережено попередній окремий JavaScript-модуль адміністратора верифікації. Під час аудиту його імпортів у поточних HTML-сторінках та інших JavaScript-модулях не знайдено.

**Стилі адміністрування vatra-verification-admin.css залишено у VATRA/**, оскільки головна сторінка їх активно завантажує. Так само залишено всі інші CSS та JS, потрібні сайту.

Старий JS не видалено назавжди: його можна відновити з Git. Перед остаточним видаленням потрібно перевірити можливі зовнішні інтеграції.

Архів SQL і попередній ZIP: [database/archive/](../database/archive/).
