# Архів старих модулів

У [legacy-ui/](legacy-ui/) збережено попередній окремий інтерфейс адміністратора верифікації (JS та CSS). Під час аудиту його файли не були знайдені в статичних посиланнях HTML або в імпортах інших модулів; активні інтерфейси адміністратора підключені окремо.

Файли не видалені назавжди: їх можна відновити з Git. Якщо є приховане зовнішнє використання, перевірте це до остаточного видалення.
