# Community topic artwork

The directory displays all 40 categories in a horizontal strip (six cards fit at wide desktop widths). Browse with the left/right arrows, a mouse wheel over the strip, a trackpad or touch swipe. All topics switches those same cards into a full grid; Show less restores the strip. The built-in covers are decorative CSS backgrounds loaded near the viewport from `assets/illustrations/`. The `topicCovers` map in `assets/js/communities/communities.js` pairs each permanent category ID with its uploaded filename without `.webp`. New uploads must be added to that map; existing files can be replaced in place. Until an image is added, the topic retains a gradient and its translated name without requesting a missing file. These assets are public; the UI suppresses image context menus and dragging but does not provide copy protection. The directory banner uses `communities.webp`.
