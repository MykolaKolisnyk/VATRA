# SQL-каталог ВАТРИ

SQL-файли винесені з **VATRA/**, щоб не змішувати серверні зміни з опублікованим фронтендом GitHub Pages.

| Папка | Зміст |
|---|---|
| [reference/](reference/) | Історичні та довідкові сценарії, згруповані за модулями: accounts, core, communities, chats-social, content, gifts, security, support, system. **Це не черга виконання**. |
| [applied/](applied/) | Скрипти, виконання яких у робочому Supabase було підтверджено. Не запускати повторно без перевірки. |
| [audits/](audits/) | Запити для читання й перевірок; [сортування таблиць](audits/ordered-live-tables.sql). |
| [archive/](archive/) | Попередні спроби нормалізації та старий ZIP. **Не застосовувати до робочої бази.** |

Деякі SQL запускалися вручну через Supabase SQL Editor, тому не всі зміни представлені у supabase_migrations.schema_migrations. Чинна схема — те, що реально показує Supabase, а не просто набір файлів.

**Перед застосуванням:** резервна копія, перевірка таблиць і прав доступу, тестове середовище та функціональні тести.

Зібрати довідковий архів (окремо від сайту):

```bash
python tools/build-vatra-sql-bundle.py
```

Файл буде створено в database/exports/ (не додається до Git).
